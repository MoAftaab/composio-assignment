# Design direction — Integration Assay

**Subject:** a product-operations due-diligence report for deciding which integrations an agent platform can build now.

**Audience:** a Composio hiring reviewer with roughly two minutes and a bias toward evidence, judgment, and operational clarity.

**Single job:** prove the research system found a trustworthy prioritization signal across 100 apps.

## Tokens

- Lab white `#F3F6F8`: working surface.
- Carbon `#132027`: primary text and structural rules.
- Protocol blue `#275DFF`: interaction and focus.
- Verified teal `#008C83`: ready and verified.
- Constraint amber `#E5A000`: conditional and outreach.
- Blocked coral `#DB4B4B`: blocked or invalid.

Typography uses IBM Plex Sans Condensed for the thesis and section statements, Source Sans 3 for reading, and IBM Plex Mono for evidence, counts, and state.

## Layout

```text

│ THESIS                                      RUN STATUS      │

├─────────────────────────────────────────────────────────────┤
│              INTEGRATION ASSAY / 100 NODES                  │

├───────────────────────┴─────────────────────────────────────┤
│ verification delta / honest misses                          │
├─────────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────────┤
│ filterable evidence ledger + machine-readable downloads     │
└─────────────────────────────────────────────────────────────┘
```

## Signature

The memorable element is the **integration assay**: every assigned app is a specimen placed in a category lane and a buildability zone. Selecting a specimen opens its evidence dossier. The atlas is both the summary and the navigation, which makes it specific to integration due diligence rather than a generic dashboard.

## Self-critique

The first concept risked becoming a familiar “editorial dashboard” with cards and oversized statistics. The revision removes decorative cards and makes evidence mapping the visual structure. Color is reserved for verdict state, section numbers are used only for the actual ordered research workflow, and motion is spent only on the single atlas-resolution moment.
